Desafio Prático Iniflex - Desenvolvedor Full Stack - JR - Prothera Tecnologia

Projeto desenvolvido como parte do processo seletivo técnico para a vaga de desenvolvedor Java na Iniflex. 
A aplicação consiste no gerenciamento, cálculo e manipulação de uma folha de funcionários em memória, aplicando boas práticas de Orientação a Objetos e recursos modernos do Java.

Tecnologias e Ferramentas
Java: Versão 17 (compatível com 11+)
Gerenciador de Dependências: Apache Maven
IDE: IntelliJ IDEA
Bibliotecas: Padrão do Java SE (`java.time`, `java.math`, `java.util.stream`)
